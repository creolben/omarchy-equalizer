for a different model than the XM6 earbuds in use.

so a big boost reads as "−7.7 dB quieter" rather than as a louder EQ.

## 1. Security

### Checked and safe
- **Sink names** → `need_sink_name` rejects `"` `\` tab newline DEL; runs in `write_fragment` and every retarget path.
- **Numbers into the fragment** → freq/gain/Q validated in `write_fragment`, `build_band_params`, `build_para_params`; string-injection PoC refused. `db_to_mult` / `printf %.6f` emit only number tokens.
- **Enumerations** → mode, type, boost, limiter go through allowlists/`case` before reaching config.
- **jq** → user values only via `--arg`/`--argjson`; only a loop integer is spliced into filters.
- **Panel → backend** → every `Process` uses an argv array (`[helper].concat(args)`); no `sh -c`, no eval.
- **QML** → all `Text` is `PlainText`; no `openUrlExternally`, `XMLHttpRequest`, `eval`, or clipboard (KeyField). `Model.js` uses only `JSON.parse`.
- **AutoEq** → hardcoded HTTPS base, TLS verification on, `--max-time`, `mktemp` temp file, parsed values number-checked.
- `install.sh` only symlinks; spectrum helper uses fixed `parec` argv; unit's first `ExecStart` is constant.

## 3. Architecture & efficiency

### Strengths
- Live updates via one `pw-cli set-param`; restart only on graph-shape change; limiter/boost always in-graph so toggles are live; presets cross-fade.
- `Model.js` is pure and tested without Qt; `Model.metrics` memo ≈1.9 ms cold / 2 µs warm.
- Background cost is gated: peak monitor, spectrum, meter animation and the 4 s poll all stop when the panel closes; meter stops on silence. Spectrum helper ≈2.5 % of one core at 40 fps.

## 5. Recommended order of work

1. **Safety & data integrity:** S1 (range clamp), S2 (never write empty state), S6 (flock + mktemp), S3, S4.
2. **P1 behaviour:** F2 (restart on pool/biquad switch), F3 (reset debounce), F1 (`preferredTarget`), each with a regression test.
3. **Uncommitted parking change (F4):** wait for a new sink index, recover parked streams on failure, add a stub mode where the sink vanishes — before committing it.
4. **Bar icon (D2)** via `FileView` watch — cheap and user-visible.
5. **Backend cost (A1):** one jq pass per command, then QML-direct `pw-cli` during drags.
6. F5, F6, F7, S5, then design items D1, D3–D5, A2 split, docs/screenshots (F15, D9).
